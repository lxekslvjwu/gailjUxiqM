# 项目简介

## 核心功能
- 基于YOLOv8的车辆检测系统，支持识别监控视角中的车辆类型（car、truck）
- 提供完整源码、5227张标注数据集、训练好的模型及训练结果
- 支持多种输入源：单张图片、图片文件夹、视频文件、本地摄像头
- 界面功能：实时显示目标位置、目标总数、置信度等信息
- 支持自定义检测参数：置信度阈值、IOU阈值
- 提供检测结果保存功能，支持批量检测并查看每一张结果
- 包含UI界面源文件，支持选择显示标签和原图，以及选择检测模型

## 适用场景
- 监控系统中的车辆检测与计数
- 交通流量分析
- 停车场管理系统
- 安防监控应用
- 车辆行为研究

## 技术特点
- 技术栈：Python 3.9 + OpenCV + PyQt5 + Ultralytics + PyTorch 1.9
- 使用PyCharm+Anaconda或VSCode+Anaconda开发环境
- 已完成模型训练，配置环境后可直接使用
- 提供完整的项目运行教程和文件结构
